# ☕ Java Foundations

> **Cheers to me learning the language I once feared the most.**

A **100-day journey from Java fundamentals to backend engineering**.

This repository documents what I learn, build, and practice throughout the journey — starting with Core Java and gradually moving toward **DSA, Spring Boot, databases, distributed systems, cloud, and AI-powered backend applications**.

This isn't a tutorial repository.

It is a record of my **actual learning and implementation**.

---

## 🎯 The Goal

By the end of these 100 days, I want to go from:

```text
"I am learning Java"
```

to:

```text
"I can build backend systems with Java."
```

The journey is focused on building both **strong fundamentals** and **practical engineering skills**.

For each stage, I'm trying to follow:

```text

Understand
  ↓
Implement
  ↓
Solve
  ↓
Build
  ↓
Review
  ↓
Commit
```

I'm trying to avoid simply copying solutions.
